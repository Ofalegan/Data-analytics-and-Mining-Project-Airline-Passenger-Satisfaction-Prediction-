# Airline Passenger Satisfaction Prediction

## Competition
- **Competition:** Playground Series S6E10 — Airline Passenger Satisfaction
- **Link:** https://www.kaggle.com/competitions/playground-series-s6e10

## Problem Definition
- **Task:** Binary classification — predict whether an airline passenger is satisfied.
- **Target:** `satisfaction` (`True` = satisfied, `False` = not satisfied)
- **Evaluation metric:** **ROC-AUC** (higher is better). The metric rewards ranking
  positive (satisfied) passengers above negative ones regardless of threshold.
